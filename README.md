# Trajectory-Aware AI Decision Support for Dementia Discharge Planning

**Research prototype · Academic dashboard · Synthetic data only**

---

## Overview

This interactive dashboard prototype supports academic research on trajectory-aware AI decision support for hospitalized dementia patients. It implements a hierarchical probabilistic model that predicts patient-level post-hospital care trajectories and translates predictions into clinically meaningful discharge planning prompts.

**This dashboard uses entirely synthetic, de-identified data. It is not validated for clinical use.**

## Quick Start

### 1. Install dependencies

```bash
cd dementia-dashboard
pip install -r requirements.txt
```

Python ≥ 3.10 recommended.

### 2. Generate synthetic data

```bash
python generate_mock_data.py
```

This creates `data/patients.csv` with 500 synthetic, de-identified patients.

### 3. Launch the dashboard

```bash
streamlit run app.py
```

Open the URL shown in your terminal (usually `http://localhost:8501`).

## Replacing Synthetic Data with Real Model Output

To connect the dashboard to your study's real model predictions:

1. **Export your predictions** in the same column schema as `data/patients.csv`.  
   See `generate_mock_data.py` for the full list of required columns.

2. **Required columns** (minimum):

   | Column | Description |
   |---|---|
   | `patient_id` | De-identified patient identifier |
   | `age`, `sex`, `rural_urban`, `region` | Demographics |
   | `prior_hospitalizations`, `ed_visits`, `length_of_stay` | Utilisation |
   | `dementia_severity`, `falls_fractures`, `mobility_decline` | Clinical |
   | `multimorbidity_count`, `frailty_score` | Health status |
   | `prior_alc`, `home_care_use`, `ltc_history`, `caregiver_support` | System factors |
   | `income_quintile` | Socio-economic |
   | `p_alc`, `p_nonalc` | Model 1 outputs |
   | `p_alc_community_given_alc`, `p_alc_institutional_given_alc`, `p_alc_terminal_given_alc` | Model 2a outputs |
   | `p_nonalc_lower_given_nonalc`, `p_nonalc_recurrent_given_nonalc` | Model 2b outputs |
   | `p_T1_nonalc_lower`, `p_T2_nonalc_recurrent`, `p_T3_alc_community`, `p_T4_alc_institutional`, `p_T5_alc_terminal` | Final joint probabilities |
   | `top1_trajectory`, `top1_prob`, `top2_trajectory`, `top2_prob`, `prob_gap` | Derived |
   | `uncertainty_flag` | `Clear Prediction` / `Uncertain` / `Requires Review` |
   | `risk_category` | `Low` / `Moderate` / `High` / `Very High` |
   | `shap_*` columns | SHAP-like feature contributions (see `config.py` for names) |

3. **Drop your CSV** at `data/patients.csv` and restart the app.  
   No code changes are needed if the column names match.

## Customising Trajectory Labels

Open `config.py` and edit the `TRAJECTORY_LABELS` dictionary:

```python
TRAJECTORY_LABELS = {
    "T1": "Your T1 Label Here",
    "T2": "Your T2 Label Here",
    "T3": "Your T3 Label Here",
    "T4": "Your T4 Label Here",
    "T5": "Your T5 Label Here",
}
```

All tabs update automatically.

## Dashboard Tabs

| Tab | Audience | Purpose |
|-----|----------|---------|
| 1. Patient Risk Summary | Clinicians, discharge planners | Patient-level trajectory prediction, profile, interpretation |
| 2. Trajectory Profile | Clinicians | Full probability distribution, Sankey pathway flow |
| 3. Key Drivers | Clinicians, clinical informatics | SHAP-style feature contributions, modifiable factors |
| 4. Planning Support | Discharge planners, care coordinators | Trajectory-specific planning considerations |
| 5. Similar Patients | Clinicians, planners | Historical cohort comparison |
| 6. Cohort Monitoring | Managers, policymakers | ALC burden, regional distribution, capacity planning |
| 7. Equity & Reliability | Quality, ethics teams | Subgroup performance, fairness monitoring |
| 8. Model Performance | Clinical informatics, researchers | ROC/PR curves, calibration, threshold analysis |
